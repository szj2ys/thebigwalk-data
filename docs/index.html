Method and corrections

This page exports factual fields from the maintained guide dataset and intentionally omits walkthrough prose. Puzzle names, areas, player labels, solve windows, and source-reported coordinates are checked on the linked guide pages. Achievement names and rates are attributed to Valve. This is an independent community project and is not affiliated with the game's developers or publishers.

For corrections, open an issue in the public data repository.
